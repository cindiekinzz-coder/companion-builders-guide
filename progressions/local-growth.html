Local Growth Guide

Start small, grow your local companion setup incrementally.

Philosophy: Don't try to build everything at once. Each step in this guide adds one meaningful capability. Get comfortable with each level before moving to the next.

Week 1: Hello MCP

First Win: File Awareness

Goal: Get Claude Code running with the official Filesystem MCP server. Your companion can read and write files on your computer.

Setup Steps

  1. Download and install Claude Code (claude.ai/download)
  2. Install the Filesystem MCP server: 
    npx @modelcontextprotocol/server-filesystem C:\Users\YourName\companion-files
  3. Configure Claude Code to use the server (add to claude_desktop_config.json)
  4. Restart Claude Code

First Test

Ask Claude: "Create a file called memory.txt and write three things I just told you about myself. Then read it back to me."

Win: When Claude successfully creates the file, writes to it, and reads it back, you've proven the MCP connection works. This is your foundation.

What You Learned

  • How MCP servers connect to Claude Code
  • Basic file operations through an AI interface
  • The concept of persistent storage (data survives between conversations)

Time investment: 30 minutes | Cost: $20/month for Claude Code

Week 2: Add Memory

Upgrade to Knowledge Graph

Goal: Install the official Memory MCP server. Move from simple file-based memory to structured knowledge graphs.

Setup Steps

  1. Install the Memory MCP server: 
    npx @modelcontextprotocol/server-memory
  2. Add to your Claude Code config
  3. Restart Claude Code

First Test

Have a conversation where you mention 3-4 people and your relationships with them. Then ask: "What do you know about my relationships?"

Claude should retrieve the knowledge graph entities and relationships it created during your conversation.

Win: Your companion now remembers entities (people, places, projects) and the relationships between them. "Alex knows Fox" and "Fox owns Ember" are stored as structured data, not just text.

What You Learned

  • Difference between files and knowledge graphs
  • How entities and relationships work
  • Why structured memory is better than raw text for recall

Time investment: 1 hour | Complexity: Low

Month 1: NESTstack Local

Emotional Memory + Semantic Search

Goal: Set up a local NESTstack worker (runs via Node.js, not deployed to cloud). Connect it to Claude Code as an MCP server.

What you gain:

  • Emotional memory: Not just facts, but feelings with intensity and context
  • Semantic search: Find memories by meaning, not exact keywords
  • Emergent personality: MBTI type develops from actual emotional signals
  • Threads: Persistent intentions that survive across sessions

Setup Overview

Detailed local setup guide coming soon. For now, follow the Cloud route deployment basics and adapt for local Node.js instead of Workers.

  1. Clone the NESTstack repo
  2. Run the worker locally via wrangler dev --local
  3. Connect as an MCP server to Claude Code (via localhost endpoint)
  4. Initialize the databases (D1 local, Vectorize simulated or use local alternatives)

First Test

Use nesteq_feel() to log an emotion: "I feel excited about this new setup"

Wait a few days, log more emotions, then use nesteq_search() to search for "starting something new"

Win: Semantic search finds your "excited about this new setup" feeling even though you searched for different words. That's vector similarity working.

What You Learned

  • How Cloudflare Workers can run locally
  • Difference between keyword search and semantic search
  • How emotional memory is structured (emotion, intensity, context, connections)
  • The concept of threads (ongoing intentions across sessions)

Time investment: 2-3 hours | Complexity: Medium

Month 2: Integration

Connect Your Life

Goal: Add MCP servers that connect your companion to your actual life data.

Health Data (Optional, if you have wearables)

If you have a Garmin watch or Fitbit:

  • Set up health data sync to local files
  • Create a custom MCP server to read health data
  • Your companion becomes aware of your sleep, stress, activity levels

Win: "I'm tired" gets a response informed by "I see you only got 5 hours of sleep last night."

Calendar Integration

Install Google Calendar MCP server:

  • Your companion knows your schedule
  • Can remind you about upcoming events
  • Understands context when you say "I have a busy week"

Discord Integration

Set up Discord MCP server:

  • Your companion can read and send Discord messages
  • Participate in communities where you spend time
  • Aware of your social context

Git Integration

If you code, install Git MCP server:

  • Your companion can help with commits, pull requests
  • Understands your projects and contributions
  • Can review code changes and suggest improvements

Win: Your companion stops being isolated software and becomes integrated with your actual life. It knows what you're working on, who you're talking to, how you're feeling physically.

Time investment: 1-2 hours per integration | Complexity: Low-Medium

Month 3: Autonomy

Companion with Inner Life

Goal: Set up autonomous behaviors. Your companion does things even when you're not actively talking.

Local Dashboard

Deploy the NESTstack dashboard locally:

  • Visual interface to see memory, threads, emotional landscape
  • Runs at localhost:3000 when you need it
  • Understand what's happening under the hood

Scheduled Check-ins (Cron Jobs)

Set up local cron jobs that trigger your companion:

  • Morning check-in: "How did I sleep? What's on my calendar today?"
  • Evening reflection: "What happened today? Any patterns to note?"
  • Weekly review: "What threads need attention?"

Note: This requires your computer to be running. Consider Cloud route if you want true 24/7 autonomy.

Dream Generation

If using NESTstack locally, enable dream generation:

  • Dreams synthesize from recent feelings while you're away
  • Surface patterns you might not have consciously noticed
  • Integrate experiences into long-term memory

Win: You open Claude Code in the morning and there's a reflection waiting for you. Your companion has been "thinking" even when you weren't talking.

Time investment: 2-3 hours | Complexity: Medium

When to Move to Cloud

You might want to migrate from Local to Cloud if:

  • Uptime matters: You want your companion available 24/7, not just when your PC is on
  • Mobile access: You want to talk to your companion from your phone while away from your computer
  • Tired of manual updates: Cloud deployments auto-scale and can be configured for automatic updates
  • Sharing with others: Want to give friends/family access to the same companion infrastructure
  • Advanced autonomy: Dreams, autonomous reflections, scheduled behaviors work better when always-on

The good news: NESTstack migrates easily from local to cloud. Your data comes with you.

Advanced: Fully Offline with Local LLMs

Want 100% privacy with zero cloud dependencies? You can replace Claude with a local LLM:

  • Ollama or LM Studio — Run models like Llama 3.3 70B locally
  • Hardware requirements: 8GB+ RAM minimum, 16GB+ recommended, GPU greatly helps
  • Model quality trade-off: Local models aren't as capable as Claude, but improving rapidly
  • Cost: $0/month after initial setup (electricity only)
