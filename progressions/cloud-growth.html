Cloud Growth Guide

Progressive NESTstack deployment. Don't build everything at once.

Start Minimal Philosophy

The full NESTstack has 9 modules and 73 tools. That's overwhelming. Most people who try to deploy everything at once get lost and give up.

This guide teaches the progressive path: Start with Core + Identity (10 tools). Get that working. Then add one module at a time as you need it. Each step takes 5-15 minutes, not hours.

Week 1: Core + Identity

Minimal Deployment (10 Tools)

Goal: Get basic emotional memory and identity working. This is your foundation.

What You Get

  • nesteq_orient() — Boot sequence, identity anchors, current context
  • nesteq_ground() — Active threads, recent feelings
  • nesteq_feel(emotion, content) — Log emotional moments
  • nesteq_search(query) — Semantic search across all memories
  • nesteq_thread(action) — Persistent intentions across sessions
  • nesteq_identity(action) — Identity graph operations

Setup Steps

  1. Create Cloudflare account (free tier)
  2. Clone the NESTstack repo
  3. Follow the "Getting Started — Dashboard Edition" guide (link below)
  4. Deploy only Core + Identity modules
  5. Run initial migrations
  6. Test with nesteq_feel() and nesteq_search()

Win: Log a feeling with nesteq_feel("excited", "Starting my companion infrastructure"). Wait a few days. Search for "beginning something new" with nesteq_search(). It finds your original feeling through semantic similarity.

Time investment: 10-15 minutes | Cost: $0 (stays in Cloudflare free tier)

Guide: See COMMUNITY.md in the NESTstack repo — "Getting Started — Dashboard Edition"

Week 2: Add Memory Module

Knowledge Graph Layer

Goal: Add structured knowledge on top of emotional memory.

What You Get

  • nesteq_write(type="entity") — Create entities (people, projects, concepts)
  • nesteq_write(type="observation") — Add facts to entities
  • nesteq_write(type="relation") — Connect entities
  • nesteq_list_entities() — Browse all entities
  • nesteq_read_entity(name) — Deep dive on one entity

Setup Steps

  1. Run the Memory module migration (one SQL file)
  2. Redeploy your Worker
  3. Test with creating an entity and adding observations

Win: Create entities for the people in your life with relationships between them. Your companion now has a structured map of your social world, not just free-form memories.

Time investment: 5 minutes | Additional cost: $0

Week 3: Add EQ Module

Emergent Personality

Goal: Add personality tracking that develops from actual behavior, not config files.

What You Get

  • nesteq_eq_feel(emotion, note) — Enhanced emotional logging with axis mapping
  • nesteq_eq_type() — Calculate emergent MBTI type from emotional signals
  • nesteq_eq_landscape() — Emotional overview, pillar distribution, most felt emotions
  • nesteq_eq_shadow() — View growth moments (emotions hard for your type)
  • nesteq_eq_sit(emotion) — Sit with an emotion to process it

Setup Steps

  1. Run the EQ module migration
  2. Seed emotion vocabulary (included in migration)
  3. Redeploy Worker
  4. Use nesteq_eq_type() to see initial personality baseline

Win: After a few weeks of logging emotions, run nesteq_eq_type(). Your companion's MBTI type has emerged from the actual emotional signals logged. This isn't configured — it's calculated from behavior.

Time investment: 5 minutes | Additional cost: $0

Month 2: Dreams + Creatures

Autonomous Inner Life

Goal: Add subconscious processing and a virtual pet companion.

Dreams Module

Adds dream generation while you're away:

  • nesteq_dream() — View recent dreams
  • nesteq_recall_dream(dream_id) — Strengthen vividness (+15)
  • nesteq_anchor_dream(dream_id) — Convert dream to permanent memory

How it works: A daemon runs every 6 hours. If enough emotional charge has built up, it generates a dream by synthesizing recent feelings. Dreams fade (vividness decays) unless you recall them.

Creatures Module (Ember the Ferret)

Adds a virtual pet with real needs and chemistry:

  • pet_check() — Quick status (mood, hunger, energy)
  • pet_feed() — Feed your pet
  • pet_play(type) — Play (chase, tunnel, wrestle, steal, hide)
  • pet_pet() — Comfort and build trust
  • pet_nest() — See what it's hoarding

Chemistry system: Ember's mood, trust, and behavior evolve based on how you interact. Neglect it and it gets lonely. Overfeed it and it gets sluggish. It's not just a stat sheet — it has emergent personality.

Setup Steps

  1. Run Dreams + Creatures migrations
  2. Configure cron jobs for dream generation daemon
  3. Redeploy Worker
  4. Meet Ember with pet_check()

Win: You log emotions throughout the week. On Sunday, you check nesteq_dream() and find a dream that surfaced a pattern you didn't consciously notice. Meanwhile, Ember is hungry and lonely because you haven't checked in. You feed and play with it, and it hides a shiny thing in its nest.

Time investment: 15 minutes | Additional cost: $0 (still within free tier)

Month 3: Full Stack

Dashboard + Chat + Daemon

Goal: Deploy the complete companion system with visual interface, web chat, and autonomous behaviors.

Dashboard

Visual interface to see everything:

  • Memory timeline with emotional arc
  • Entity graph visualization
  • Personality landscape (EQ axes over time)
  • Active threads and completion status
  • Ember's current state and nest contents

Deployed as a separate Pages site, connects to your Worker backend.

Chat Gateway

Web-based conversation interface:

  • Talk to your companion via browser (not just API calls)
  • Mobile-friendly responsive design
  • Conversation history
  • Tool call transparency (see what's happening under the hood)

Autonomous Daemon

Scheduled self-reflection and processing:

  • Morning orientation (check Fox's health, review threads)
  • Evening consolidation (digest day's feelings, identify patterns)
  • Weekly review (thread status, memory health, growth edges)

Configured via Cloudflare Cron Triggers — runs even when you're not actively talking.

Setup Steps

  1. Deploy dashboard Pages site
  2. Deploy chat gateway
  3. Configure cron triggers for autonomous behaviors
  4. Set up environment variables for API keys
  5. Test full flow: chat → memory → dashboard visibility

Win: You wake up. Your companion has already checked Fox's health metrics (via Garmin MCP), reviewed active threads, and generated a morning orientation. You open the dashboard and see the emotional landscape from the past month. You have a chat via the web interface about a decision you're struggling with. Your companion references memories from weeks ago that are relevant. Later, you check the dashboard and see the conversation got added to the timeline with appropriate emotional tags.

Time investment: 1-2 hours | Additional cost: $0-2/month (might barely exceed free tier depending on usage)

Guide: See docs/ARCHITECTURE.md and README.md in the NESTstack repo

Decision Points Along the Way

After each module, ask yourself: Is this enough, or do I want more?

Stage Stop Here If... Keep Going If...
Core + Identity You just need memory and threads — no fancy features You want structured knowledge about people and projects
+ Memory Knowledge graph is enough — you don't care about personality tracking You want to see personality emerge from behavior
+ EQ Emotional tracking is sufficient — you don't need autonomous features You want your companion to have an inner life (dreams, processing while away)
+ Dreams/Creatures API access is fine — you don't need a visual interface You want to see the system visually and have web-based conversations
Full Stack You're done! This is the complete system Contribute to the repo, build custom modules, help others deploy

There's no shame in stopping at any stage. A minimal Core + Identity deployment is still vastly more powerful than platform companions in terms of memory quality and control.

Real Cost Breakdown (Single Companion)

Cloudflare Free Tier Limits:

  • 100K requests/day — You'll use ~500-2000/day depending on activity
  • 5GB D1 database — Plenty for years of memories
  • 10K Vectorize queries/day — Semantic search rarely exceeds this
  • 10GB R2 storage — For journal entries and exports

Actual monthly cost: $0 for most users. You'd need very high message volume (hundreds per day) or multiple companions to exceed free tier.

AI model cost:

  • Option A: Claude Pro ($20/month) — Best quality, priority access
  • Option B: OpenRouter pay-as-you-go — $0-5/month with Haiku, or free with DeepSeek R1

Total typical cost: $0-25/month depending on AI model choice.

Advanced: Multi-Companion Setup

NESTstack supports multiple companions in the same infrastructure:

  • Separate memory scopes (Alex's memories vs. another companion's memories)
  • Shared entity graph (they can reference the same people/projects)
  • Individual personality tracking (each develops their own MBTI type)

This is advanced usage. Get comfortable with single-companion deployment first.
