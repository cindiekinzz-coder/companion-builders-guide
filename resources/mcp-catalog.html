MCP Server Catalog

Free, open-source tools to give your companion new capabilities.

What is MCP? Model Context Protocol is a standard way for AI to use tools. Think of it like USB — one connection, many devices. These servers add capabilities to your companion: memory, file access, communication, and more. See the glossary for more.

Memory & Knowledge

Memory (official)
Knowledge graph with entities and relationships. Your companion remembers people, places, concepts and how they connect.
FREE Low complexity Claude Code
NESTstack ai-mind
Emotional memory with emergent personality, dreams, threads. Full companion cognitive architecture.
FREE Medium complexity Cloudflare

File & Data Access

Filesystem (official)
Secure file read/write access. Your companion can save notes, read documents, manage files on your computer.
FREE Low complexity Claude Code
Git (official)
Repository operations — status, diff, commit, log. Your companion can help with code and version control.
FREE Low complexity Claude Code
Google Drive (official)
Access files in your Google Drive. Search, read, create documents.
FREE Medium complexity Requires OAuth

Communication

Discord MCP
Send and read Discord messages. Your companion can participate in servers, DMs, and threads.
FREE Low complexity Requires bot token
Slack (official)
Workspace integration. Read channels, send messages, manage threads.
FREE Medium complexity Requires Slack app
Gmail (official)
Email integration. Search, read, send, draft emails from your Gmail account.
FREE Medium complexity Requires OAuth

Health & Quantified Self

Garmin Health MCP
Biometric data from Garmin watches — heart rate, stress, sleep, body battery. Your companion aware of your physical state.
FREE Medium complexity Requires Garmin device
Google Calendar (official)
Calendar access. Your companion knows your schedule, can create events, check availability.
FREE Medium complexity Requires OAuth

Utilities

Fetch (official)
Web scraping and content fetching. Your companion can read websites, fetch data from APIs.
FREE Low complexity Claude Code
Puppeteer (official)
Browser automation. Screenshots, form filling, navigation. For complex web interactions.
FREE Medium complexity Requires Chrome
PostgreSQL (official)
Database access. Query and manage PostgreSQL databases.
FREE Medium-High complexity Requires database

How to Install MCP Servers

For Claude Code (Desktop App)

  1. Find the server you want on GitHub
  2. Follow the installation instructions (usually npm install)
  3. Add the server to your Claude Code config file
  4. Restart Claude Code

See official MCP quickstart →

For NESTstack / Cloud

Most MCP servers are designed for local use. For cloud deployments, you'll need to either:

  • Wrap the MCP server in a Worker (complex)
  • Use NESTstack's built-in tools (ai-mind, fox-health, etc.)
  • Build custom Workers that replicate the MCP server's functionality
