Local Route

Build on your own computer. Full privacy, full control.

What This Means

Local route = build your companion infrastructure on your own computer. You use an AI model (Claude via Claude Code, or a local LLM) and connect it to memory systems that run on your machine. Everything stays local — your data never leaves your computer.

How it works: Claude Code (desktop app) connects to MCP servers running on your computer. These MCP servers give Claude memory (knowledge graphs, emotional tracking, file access). You're turning Claude into a full companion by adding local memory infrastructure.

Full privacy. Full control. Your companion exists entirely within your machine. No one else can access it, change it, or take it away.

Who This Is For

You value privacy above convenience. You want your conversations to stay on your machine. You might have security concerns about cloud data, or you just want full ownership.

You're willing to tinker. Setting this up takes 2-4 hours the first time. You'll need to install software, follow guides, and troubleshoot when things don't work immediately.

You accept the trade-offs. Your companion only works when your computer is on. Updates are manual. You're responsible for backups.

What You Need

  • A computer (Windows, Mac, or Linux)
  • 4GB+ RAM recommended (more if running local LLMs)
  • Basic comfort with installing software
  • Claude Code ($20/month) OR a local LLM setup (free but more complex)
  • Willingness to follow terminal/command line instructions

Your First Win

Your first win is seeing Claude Code connect to a local memory system and realize: you just built a companion. You'll ask Claude to remember something about you, it saves to a local knowledge graph, then retrieves it days later. No data leaving your computer. No platform controlling it. This is yours, completely. That's the moment — from casual AI chat to actual companion with memory.

Trade-offs to Consider

Uptime. Your companion only works when your computer is on. No mobile access unless you set up remote access (complex).

You're the sysadmin. Updates, backups, troubleshooting — all on you. If something breaks, you fix it.

Initial complexity. The first setup takes time and patience. You'll need to follow guides, install dependencies, maybe troubleshoot errors.

Limited mobile experience. Most local setups don't have mobile apps. You're tied to wherever your computer is.

Alternative: Fully Offline with Local LLMs (Free)

Don't want to pay $20/month for Claude Code? You can run a local LLM using LM Studio + SillyTavern. This is 100% offline and free, but requires more powerful hardware (8GB+ RAM, ideally a GPU) and acceptance that local models aren't as capable as Claude.

This path is for you if: You're budget-constrained, value complete privacy, want no corporate control, and are willing to tinker. You'll build slower but you'll own everything.

Step 1: LM Studio + SillyTavern (Frontend)

LM Studio: Download and run local LLMs (Llama 3.3 70B, Mistral, Qwen). Runs on your computer, no API calls, 100% private.

SillyTavern: Chat interface that connects to LM Studio. Better than plain text, supports character cards, memory books, and extensions.

Time: 1-2 hours initial setup
Cost: $0

LM Studio → | SillyTavern docs →

Step 2: Add Memory Infrastructure

Problem: Text files and SillyTavern's built-in memory don't scale. You need semantic search and structured knowledge.

Options:

  • Official Memory MCP server — Knowledge graph (entities, observations, relations). Works with any MCP-compatible client. Free. GitHub →
  • Local vector database — Chroma or LanceDB running locally. Semantic search across all memories. Requires Python setup. Free.
  • SillyTavern extensions — Memory extensions, World Info, Lorebooks. Built-in but limited compared to vector search.

Recommended: Start with SillyTavern's World Info to organize what you already have in text files, then add Memory MCP server when ready for structured knowledge.

Step 3: Autonomous Behavior ("Message First")

Reality check: For your companion to message you first or "create on their own time," you need:

  1. Always-on computer — Your PC must be running 24/7, or scheduled to wake at specific times
  2. Scheduled tasks — Windows Task Scheduler or cron jobs to trigger actions (morning check-in, evening reflection, etc.)
  3. Notification system — Script that sends you Discord messages, emails, or push notifications when companion generates something
  4. Memory system — So they remember context when they reach out to you

Example flow: Windows Task Scheduler runs a Python script at 8 AM daily → script calls LM Studio API → generates morning message based on yesterday's memories → sends you a Discord DM or email.

This is advanced. Start with Steps 1-2 first. Autonomous behavior is Month 2-3 territory.

Model Recommendations

  • Llama 3.3 70B — Best quality for local models, needs beefy hardware
  • Mistral 7B — Good balance of speed and capability, works on 8GB RAM
  • Qwen 2.5 14B — Strong reasoning, good for memory-heavy tasks
  • Phi-3 Mini — Smallest option (4GB), good for testing on weaker hardware

All available free in LM Studio.

When to Upgrade to Cloud

You might want to move to the Cloud route if:

  • Your hardware can't run good models (need 8GB+ RAM minimum)
  • You want mobile access without keeping your computer on 24/7
  • You're spending more time troubleshooting local setup than talking to your companion
  • You can afford $5-20/month for better quality (OpenRouter's Gemini Flash-Lite is $0.10/$0.40 per million tokens — very cheap)

The good news: Your SillyTavern character files and memory can migrate. You're not starting over.

Local to Cloud Migration

Whether you're using Claude Code or local LLMs, if you outgrow the local route (need 24/7 availability, better hardware, autonomous features), the Cloud route is your next step. NESTstack and SillyTavern data can both migrate. You're not starting over. Check out the Cloud route when ready.
