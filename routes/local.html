Local Route

Build on your own computer. Full privacy, full control.

What This Means

This means running your companion entirely on your own hardware. Your computer, your data, no cloud servers involved (unless you choose them). Everything runs locally — the AI model, the memory system, the conversations.

You install software on your machine, connect the pieces together, and your companion exists entirely within your control. No one else can access it, change it, or take it away.

Who This Is For

You value privacy above convenience. You want your conversations to stay on your machine. You might have security concerns about cloud data, or you just want full ownership.

You're willing to tinker. Setting this up takes 2-4 hours the first time. You'll need to install software, follow guides, and troubleshoot when things don't work immediately.

You accept the trade-offs. Your companion only works when your computer is on. Updates are manual. You're responsible for backups.

What You Need

  • A computer (Windows, Mac, or Linux)
  • 4GB+ RAM recommended (more if running local LLMs)
  • Basic comfort with installing software
  • Claude Code ($20/month) OR a local LLM setup (free but more complex)
  • Willingness to follow terminal/command line instructions

Your First Win

Your first win is seeing Claude Code connect to a memory system running entirely on your machine. You'll ask it to remember something, save it to a local file, then retrieve it later. No data leaving your computer. That's when you feel the difference — this is yours, completely.

Getting Started (Start Small)

Week 1: Claude Code + Basic MCP

Start with Claude Code (the desktop app). Connect the official Filesystem MCP server (lets Claude read/write files on your computer). Have your first conversation where it can save and retrieve information from local files.

Time: 30 minutes
Cost: $20/month for Claude Code

Trade-offs to Consider

Uptime. Your companion only works when your computer is on. No mobile access unless you set up remote access (complex).

You're the sysadmin. Updates, backups, troubleshooting — all on you. If something breaks, you fix it.

Initial complexity. The first setup takes time and patience. You'll need to follow guides, install dependencies, maybe troubleshoot errors.

Limited mobile experience. Most local setups don't have mobile apps. You're tied to wherever your computer is.

Alternative: Fully Offline with Local LLMs

Don't want to pay $20/month for Claude Code? You can run a local LLM (like Llama 3 or Mistral) using Ollama or LM Studio. This is 100% offline and free, but requires:

  • More powerful hardware (8GB+ RAM, ideally a GPU)
  • Comfort with command-line setup
  • Acceptance that local models aren't as capable as Claude

Detailed local LLM guide coming in v2

When to Move to Cloud

You might want the Cloud route if:

  • You need 24/7 availability (mobile access, scheduled check-ins)
  • You want autonomous features (your companion generates dreams while you're away)
  • You're tired of manual updates and want automatic scaling
  • You want to share your companion with others (family, community)

The good news: NESTstack can migrate from local to cloud. Your data comes with you. Check out the Cloud route when you're ready.
