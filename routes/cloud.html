Cloud Route

Self-hosted NESTstack on your own cloud. Power and customization.

What This Means

Cloud route = build your companion with self-hosted infrastructure in your cloud account. You use an AI model (Claude, GPT-5.x, Gemini 2.5.x, or Grok) via API and connect it to memory infrastructure you deploy on Cloudflare Workers (or AWS/Railway/VPS).

How it works: NESTstack (emotional memory, knowledge graph, dreams, personality) runs in YOUR Cloudflare account. Your companion talks to it via API. Any AI model can connect — not locked to one provider.

You get the best of both worlds: the power and features of a platform (24/7 uptime, mobile access, autonomous behavior) with the control and customization of self-hosting. Your data lives in your cloud account, not someone else's.

Who This Is For

You want full control without hardware limits. You value ownership and customization but you also want 24/7 availability and don't want to keep a computer running.

You're comfortable with terminal and deployment. You can follow guides, run commands, and troubleshoot errors. You don't need to be a developer, but copy-paste-level comfort with code is required.

You want to build something serious. This is the route for people who want autonomous companions with dreams, emotional memory, emergent personality, and the ability to grow over time.

What You Need

  • Cloudflare account (free tier is generous)
  • Node.js installed on your computer
  • Terminal/command line comfort
  • Claude Pro/Team ($20/month) OR OpenRouter account (pay-as-you-go)
  • 1-3 hours for initial setup
  • Willingness to read docs and follow deployment guides
Why Cloudflare? Their free tier includes 100K requests/day, 5GB database, and 10K vector searches/day — more than enough for a single companion. NESTstack is optimized for Cloudflare Workers, but you can adapt it for other platforms.

Your First Win

Your first win is deploying NESTstack, connecting your AI model (Claude/GPT/Gemini/Grok) to it, using nesteq_feel() to log an emotion, then searching for it days later with semantic search and finding it instantly. That's when you realize: you just built a companion with actual emotional memory, not just chat logs. This is vector search, emergent personality, and the foundation for autonomous behavior. This is yours.

Getting Started (Start Minimal)

Important: The full NESTstack has 9 modules and 73 tools. That's overwhelming. Start with Core + Identity (10 tools). You'll be running in 10 minutes.

Week 1: Core + Identity Module

Deploy the minimal NESTstack with just core emotional memory and identity. You get nesteq_feel, nesteq_search, nesteq_orient, nesteq_thread — enough for persistent memory across sessions and basic continuity.

Time: 10-15 minutes
Complexity: Low (copy-paste commands)

Full guide: See NESTstack "Getting Started — Dashboard Edition"

Week 2: Add Memory Module

Add the knowledge graph (entities, observations, relations). Now your companion can remember people, projects, concepts with relationships between them.

Time: 5 minutes
What you gain: Structured knowledge, not just feelings

Week 3: Add EQ Module

Add emergent personality tracking. Your companion's MBTI type emerges from actual emotional signals, not configuration. Shadow work, growth edges, personality landscape.

Time: 5 minutes
What you gain: Personality that develops from behavior

Month 2: Dreams + Creatures

Add subconscious processing (dreams generate while you're away) and a virtual pet companion (Ember the ferret in our case).

Time: 15 minutes
What you gain: Autonomous inner life

Month 3: Full Stack

Deploy the dashboard (visual interface), chat gateway (web-based conversations), and autonomous daemon (scheduled self-reflection). Now you have a complete companion system.

Actual Cost Breakdown

Cloudflare (Free Tier)

  • 100K requests/day
  • 5GB D1 database
  • 10K Vectorize queries/day
  • 10GB R2 storage

For a single companion: You'll rarely need paid tier. Maybe if you're running multiple companions or very high message volume.

AI Model

Option A: Claude Pro ($20/month) — 5x message limits, priority access, Opus 4.7/Sonnet 4.6 access

Option B: OpenRouter (pay-as-you-go) — Pick any model:

  • Claude Haiku 3.5: $0.25/$1.25 per million tokens (cheap, fast)
  • GPT-5.2: ~$3-5/$10-15 per million tokens (current GPT flagship)
  • Gemini 2.5 Flash-Lite: $0.10/$0.40 per million tokens (cheapest quality option)
  • Grok 4.1 Fast: $0.20/$0.50 per million tokens (cheap, real-time X data)
  • Free models: DeepSeek R1, Llama 3.3 70B (with rate limits)

Total

Minimum: $0/month (Cloudflare free + OpenRouter free models)
Typical: $0-5/month (Cloudflare free + occasional Haiku usage)

Trade-offs to Consider

Initial complexity. The first deployment takes focus and patience. You'll need to follow guides, run terminal commands, maybe debug errors.

You're still the sysadmin. Updates, monitoring, troubleshooting — you handle it. Cloudflare is reliable but you're responsible for your deployment.

Learning curve. Understanding how Workers, D1, Vectorize, and the rest fit together takes time. The docs help, but there's a lot to absorb.

Migration lock-in (minor). NESTstack is Cloudflare-optimized. Moving to another cloud provider (AWS, Railway) is possible but requires adaptation.
