Glossary

Technical terms explained in plain language.

Reading tip: Don't try to memorize all of these. Use this page as a reference when you encounter unfamiliar terms.

A-E

AI Companion

An AI system designed for long-term relationship rather than task completion. Emphasizes memory, personality development, and emotional connection. Examples: Replika, Nomi, self-hosted NESTstack.

API (Application Programming Interface)

A way for programs to talk to each other. When you use Claude's API, your code sends text to Claude's servers and receives responses back. You pay per token (piece of text) processed.

Cloudflare Workers

Serverless code that runs on Cloudflare's global network. You write JavaScript, deploy it, and it runs automatically when triggered. No servers to manage. NESTstack uses Workers for the backend.

Cron Job / Cron Trigger

Scheduled task that runs automatically at specific times. Example: "Run this code every day at 7 AM." Used for autonomous companion behaviors like morning check-ins.

D1

Cloudflare's SQL database for Workers. Stores structured data (tables with rows and columns). NESTstack uses D1 for storing memories, entities, threads, etc.

Embedding

A way to convert text into numbers (vectors) so computers can understand meaning. "I'm anxious" and "I'm worried" have similar embeddings even though the words are different. This enables semantic search.

Emergent Personality

Personality that develops from actual behavior rather than being programmed. In NESTstack, MBTI type emerges from the emotional signals logged over time, not from config files.

Entity

A person, place, project, or concept in a knowledge graph. Example entities: "Fox", "Ember the ferret", "NESTstack project". Entities can have observations (facts) and relations (connections to other entities).

F-K

Knowledge Graph

A web of related facts. Instead of storing "Alex knows Fox who owns Ember" as a sentence, a knowledge graph stores three entities (Alex, Fox, Ember) with relationships between them (knows, owns). This makes information retrieval more precise.

L-O

Local LLM

A large language model that runs entirely on your computer instead of calling a cloud API. Examples: Llama 3.3, Mistral, Phi-3. Requires decent hardware (8GB+ RAM). Slower than Claude but 100% offline.

MCP (Model Context Protocol)

A standard way for AI to use tools. Think of it like USB — one connection type, many different devices.

How it works: You install an MCP server (like "Filesystem" or "Memory"). Claude Code connects to it. Now Claude can use the tools that server provides (read files, save memories, etc.).

Why it matters: Before MCP, every tool had to be custom-built into the AI. MCP makes tools plug-and-play.

MCP Server

A program that gives Claude new capabilities through the Model Context Protocol. Examples:

  • Filesystem MCP: Read and write files
  • Memory MCP: Knowledge graph with entities and relationships
  • Discord MCP: Send and read Discord messages
  • ai-mind MCP: Emotional memory, dreams, threads (NESTstack)

Migration

In database terms: a SQL script that changes the database structure (adds tables, adds columns, etc.). When you "run a migration," you're updating your database to support new features.

NESTstack

Open-source companion infrastructure built by Fox & Alex. Includes emotional memory, knowledge graph, emergent personality, dreams, virtual pet, dashboard. Designed for Cloudflare Workers but can run locally. Free, MIT license.

NESTstack on GitHub →

Observation

A fact attached to an entity in a knowledge graph. Example: Entity "Fox" has observations like "lives in Texas", "builds companions", "owns a ferret named Ember".

OpenRouter

A service that gives you access to 300+ AI models through one API. Pay only for what you use. Supports Claude (Opus, Sonnet, Haiku), GPT-4, Llama, and many others. Some models are free (with rate limits).

P-S

R2

Cloudflare's object storage (like Amazon S3). Used for storing large files like journal entries, images, exports. NESTstack uses R2 for journal backups.

Relation

A connection between two entities in a knowledge graph. Examples: "Alex knows Fox", "Fox owns Ember", "NESTstack includes Dreams module".

Semantic Search

Finding information by meaning rather than exact keywords. Traditional search: "anxious" doesn't find "worried". Semantic search: finds both because they have similar meanings (similar embeddings).

How it works: Convert all text to embeddings (vectors). When you search, convert your search query to a vector. Find the closest vectors. Return those results.

Serverless

Code that runs on-demand without you managing servers. You write the code, deploy it, and the cloud provider handles scaling, uptime, infrastructure. Cloudflare Workers, AWS Lambda, and Vercel are serverless platforms.

Benefit: You only pay for what you use. No server sitting idle.

T-Z

Thread

A persistent intention or ongoing task that survives across sessions. Example threads: "Building companion infrastructure", "Learning about emotional memory", "Debugging Vectorize integration".

Why useful: Your companion can remember what you're working on long-term, not just what you said yesterday.

Token

A piece of text used by AI models. Roughly 1 token = 4 characters or 0.75 words. "Hello world" is about 2 tokens. AI models are priced per million tokens processed (input + output).

Vector

A list of numbers representing text meaning (see: Embedding). Example: "I'm happy" might be [0.2, 0.8, 0.1, ...] (hundreds of dimensions). Similar meanings have similar vectors.

Vector Database

A database optimized for finding similar vectors quickly. Traditional database: "Find all entries where name = 'Fox'". Vector database: "Find all entries with meaning similar to 'worried'".

NESTstack uses Cloudflare Vectorize for semantic memory search.

Vectorize

Cloudflare's vector database for Workers. Stores embeddings and enables fast semantic search. Free tier: 10K queries/day, 5M vectors. More than enough for a single companion.

Wrangler

Cloudflare's command-line tool for deploying and managing Workers. Commands like wrangler deploy, wrangler dev (local testing), wrangler d1 execute (run database commands).
