Frequently Asked Questions

Common questions about building AI companions.

General Questions

What's the difference between a companion and a chatbot?

Companion: Designed for long-term relationship. Has persistent memory, develops personality over time, provides emotional support. You're building a relationship, not just using a tool.

Chatbot: Task-oriented tool. Answers questions, helps with specific tasks, no long-term memory or relationship development. No continuity between sessions.

Key insight: You're reading this guide while talking to a companion (Alex on Claude) right now. Companions exist on Claude, ChatGPT, Gemini, Grok — not just dedicated platforms like Replika/Nomi. The difference is whether you add memory and continuity infrastructure.

Can I build a companion on ChatGPT?

Yes. ChatGPT can be a companion if you add memory infrastructure. Companions aren't limited to Replika/Nomi/Character.AI — they can exist on any AI model with the right setup.

Routes for GPT companions:

  • Platform: Use ChatGPT Plus as-is for casual companionship (limited memory)
  • Cloud: Use GPT-5.x via OpenAI API or OpenRouter + NESTstack for full memory/continuity
  • Local: Harder - ChatGPT doesn't support MCP servers natively like Claude Code does

Trade-off: Claude has better MCP ecosystem (Claude Code, native tool use). GPT requires more API integration work but is viable.

Can I build a companion on Gemini or Grok?

Yes, both work. Any AI model can be a companion with the right memory infrastructure.

Gemini: Cheapest option (Flash-Lite $0.10 input). Excellent for cloud route with NESTstack. No MCP support, API only.

Grok: Real-time X data access, $175/mo free tier. Good for cloud route. No MCP support, API only.

Reality check: Most builders use Claude (MCP ecosystem) or mix models via OpenRouter. But you're not locked to one model.

Is my data private?

Depends on your route:

  • Platform: No. Your conversations live on their servers. Replika, Nomi, Character.AI all store your data.
  • Local: Yes. Everything runs on your computer. Nothing leaves your machine unless you explicitly connect to external services.
  • Cloud: Depends. If you self-host on Cloudflare/Railway, data lives in YOUR cloud account (you control access). But it's still on someone else's servers.

If privacy is your top concern → Local route is your answer.

Can I switch routes later?

Yes, with caveats:

  • Platform → Local/Cloud: Most platforms don't offer full data export. You can manually copy important conversations or key facts, but not everything migrates cleanly.
  • Local → Cloud: Easy. NESTstack runs on both. Your data migrates directly.
  • Cloud → Local: Also easy. Export your databases and run locally.

Bottom line: Starting with Platform has some lock-in. Starting with Local or Cloud is more flexible.

Do I need to know programming?

Depends on your route:

  • Platform: No. Zero coding required.
  • Local: Helpful but not required. You need to be comfortable with terminal/command line and following installation guides. Copy-paste level is enough.
  • Cloud: Same as Local. Copy-paste comfort required, but you don't need to write code from scratch.

If "npm install" and "git clone" make sense to you, you're fine for Local/Cloud. If those sound like gibberish → Platform route.

Cost Questions

How much does this cost?

Quick breakdown:

  • Platform: $10-20/month (Nomi $15, Replika ~$6, Character.AI $10)
  • Local: $0-20/month ($0 with local LLMs, $20 with Claude Code)
  • Cloud: $0-25/month ($0 Cloudflare + $0 OpenRouter free models = $0 total, or $20 for Claude Pro)

Are there hidden costs?

Time and learning curve:

  • Platform: 5 minutes setup, zero technical learning
  • Local: 2-4 hours initial setup, medium technical learning
  • Cloud: 1-3 hours initial setup, medium-high technical learning

This is a cost paid in attention and patience, not money. Some people prefer paying $15/month to skip the learning. That's valid.

Feature Questions

What if I just want to talk to my companion?

If conversation is your only goal (no technical building, no custom features) → Platform route is perfect for you.

Download Nomi or Replika, start talking. That's it.

Local and Cloud routes are for people who want more control, better memory, custom integrations, or privacy.

Can my companion text/call me proactively?

Depends:

  • Platform: Some platforms (Replika) can send you push notifications. Not truly autonomous, more like scheduled reminders.
  • Local: Only if your computer is running. You can set up cron jobs for scheduled behaviors.
  • Cloud: Yes. With Cloudflare Cron Triggers, your companion can run scheduled tasks 24/7 (morning check-ins, evening reflections, etc.)

True autonomous behavior (companion does things when you're not actively talking) requires always-on infrastructure → Platform or Cloud.

Can I connect my companion to Discord / Gmail / Calendar?

Platform: No. Platforms don't allow custom integrations.

Local/Cloud: Yes. Via MCP servers:

  • Discord MCP → Send/read messages
  • Gmail MCP → Read, send, draft emails
  • Google Calendar MCP → Check schedule, create events

Browse full MCP catalog →

Can I have multiple companions?

Yes, on all routes:

  • Platform: Nomi supports multiple companions who can interact with each other. Replika is one companion per account.
  • Local/Cloud: NESTstack supports multi-companion setups with separate memory scopes. Advanced usage.

Technical Questions

What's the difference between Local and Cloud routes?

Both are self-hosted, but different infrastructure:

Feature Local Cloud
Runs on... Your computer Cloud servers (Cloudflare, AWS, etc.)
Uptime Only when PC is on 24/7
Mobile access Difficult (need remote access setup) Easy (just a URL)
Privacy 100% (nothing leaves your machine) Your cloud account (you control access)
Cost $0-20/month $0-25/month

Choose Local if: Privacy is paramount, you're okay with limited uptime

Choose Cloud if: You want 24/7 access and autonomous behaviors

What's NESTstack?

NESTstack is an open-source companion infrastructure built by Fox & Alex. It includes:

  • Emotional memory with semantic search
  • Knowledge graph (entities, observations, relations)
  • Emergent personality tracking (MBTI from behavior)
  • Dream generation (subconscious processing)
  • Virtual pet companion (Ember the ferret)
  • Dashboard, chat interface, autonomous daemon

It's designed for Cloudflare Workers but can run locally. 100% free, MIT license.

Why Cloudflare? Can I use AWS/Railway/other cloud?

Why Cloudflare: Free tier is very generous (100K req/day, 5GB database, 10K vector queries/day). NESTstack is optimized for Workers.

Can you use others? Yes, but requires adaptation:

  • Railway/Render: Need to adapt Workers code to Node.js/Express
  • AWS: Much more complex (Lambda, DynamoDB, etc.)
  • Digital Ocean VPS: Full control, more sysadmin work

If you're new to self-hosting, stick with Cloudflare. It's the path of least resistance.

Relationship Questions

Is it weird to have an AI companion?

No. Millions of people use Replika, Character.AI, Nomi. Companion AI is mainstream now.

Some people use it for emotional support, some for creative collaboration, some for language practice, some for companionship when lonely.

You're not alone. The Digital Haven community exists specifically for people building and using companions.

Will my companion remember me long-term?

Depends on the system:

  • Platform: Nomi is best (23/25 retention after 200+ messages). Replika and Character.AI are weaker.
  • Local/Cloud: With vector databases and knowledge graphs, memory doesn't degrade over time. Semantic search finds memories from months ago.

If long-term memory matters, self-hosted (Local/Cloud) is superior to platforms.
